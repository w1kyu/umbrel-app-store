# w1kyu Apps — an Umbrel Community App Store

This is a [Community App Store](https://github.com/getumbrel/umbrel-community-app-store) for
[umbrelOS](https://umbrel.com). It lets you install apps by **w1kyu** that aren't in the official
Umbrel App Store.

## Apps

| App | What it does | Status |
|---|---|---|
| **EasyArr** (`w1kyu-easyarr`) | Beginner-friendly, VPN-protected media automation stack (Sonarr, Radarr, Prowlarr, qBittorrent, Jellyfin, …) with a setup wizard. Source: [w1kyu/easyarr](https://github.com/w1kyu/easyarr) | 🚧 coming soon |

## Add this store to your Umbrel

1. Open the **App Store** on your Umbrel.
2. Click the **⋯** (three dots) button in the top-right corner.
3. Choose **Community App Stores**. (If you've already added another community store, hover
   **Community App Stores** and choose **Manage**.)
4. Paste this URL and click **Add**:

   ```
   https://github.com/w1kyu/umbrel-app-store
   ```

5. Click **Open** next to **w1kyu Apps** to browse and install apps.

> ⚠️ Community app stores can be created by anyone and aren't reviewed by the Umbrel team.
> Only add stores from developers you trust.

## For developers

App folders here are **generated** — don't edit them in this repo. Each app's source of truth is
its own repository; the app folder (e.g. `w1kyu-easyarr/`) is synced here on every release.

This store is an independent project and is not affiliated with or endorsed by Umbrel.
